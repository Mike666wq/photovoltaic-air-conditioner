## 项目简介

本项目面向 **光储直柔空调实验平台**（光伏 + 储能 + 热泵 + 相变蓄能 + 末端空调），构建一个 **Web 端实验数据可视化系统**。

- **阶段 1（基础）**：把 `原理图.jpg` 1:1 还原成 Web 页面，加上三大流体粒子动画 + 部件内部动画 + 模式切换响应，用仿真引擎驱动动画。
- **阶段 2**：接入实验采集系统的真实数据（PDF + XLSX），驱动原理图页面，展示历史数据回放。当前已完成 M2-β 的前端解析、数据集保存、仪表绑定与时序回放闭环。
- **阶段 3（最后）**：基于采集数据生成 ECharts 多维图表，搭建 1920×1080 数据分析大屏。

> **明确不做**：硬件控制、IoT 接入、用户体系、移动端适配。

## 已知风险

1. **动画保真度是 M1 最大风险**：仿真引擎是动画的唯一数据源，禁止硬编码动画。
2. **Canvas 2D 性能天花板**：超过 ~500 个粒子或部件内部细节很多时，需评估是否上 PixiJS（WebGL）。
3. **数据完整性**：当前 PDF **不包含** PV 功率、蓄电池 SOC、热泵功率等关键字段，M2 接入后这些部件只能显示静态默认状态。
4. **PDF 解析稳定性**：力控导出的 PDF 表格结构可能变化，需要 Zod schema 校验兜底。
5. **跨日数据合并**：PDF（7/14）与 XLSX（7/15）不重叠，需分段展示而非平滑过渡。
6. **响应式兼容**：M1 不支持移动端，桌面 ≥ 1280px / 平板 ≥ 768px。
